# Global-Fuel-Prices-and-Taxation-Trends-A-Comprehensive-Glo
A global analysis of fuel prices and taxation trends (2020–2026) across 84 countries and 7 regions. Using 27,468 records and 10 variables, this project explores petrol, diesel and LPG prices, taxes, subsidies, income levels and regional variations through interactive visualizations to support data-driven insights.
